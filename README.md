# CGV-Bot

CGV 좌석을 5초 간격으로 확인해, 사용자가 지정한 선호 좌석 중 가장 우선순위가 높은 연속 좌석을 선택하는 북마클릿입니다.

버전 2.0은 2026년 리뉴얼된 CGV 웹 예매 화면(`/cnm/selectVisitorCnt`)에 맞춰 다시 작성했습니다. 예전 `#ticket_iframe`, jQuery, `$.cgv.data`, `loadSeatInfo`, `ticketStepNext` 같은 비공개 API에는 의존하지 않습니다.

## 설치

Node.js 18 이상이 필요합니다.

```sh
npm install
npm run build
```

생성된 `dist/index.html`을 브라우저에서 열고 **CGV 자동 예매** 링크를 북마크바로 드래그합니다.

## 사용 방법

1. CGV에서 영화, 극장, 상영 시간과 관람 인원을 선택합니다.
2. 좌석 영역의 **선택** 버튼을 눌러 큰 좌석 선택 창을 엽니다.
3. 북마크바의 **CGV 자동 예매**를 실행합니다.
4. 원하는 좌석을 선호 순서대로 클릭합니다. 현재 매진된 좌석도 선호 좌석으로 지정할 수 있습니다.
5. **감시 시작**을 누릅니다.
6. 조건에 맞는 연속 좌석이 생기면 CGV의 실제 좌석 선택 동작을 실행하고 알립니다.

기본값은 좌석 확보 후 결제 화면까지 자동으로 이동합니다. 원치 않으면 감시를 시작하기 전에 해당 옵션을 끄세요. 결제 자체는 자동으로 완료하지 않습니다.

## 개발

```sh
npm test
npm run build
```

- `bookmarklet.js`: DOM 어댑터, 선호 좌석 UI, 폴링 상태 머신, 테스트 가능한 좌석 선택 함수
- `build.js`: Terser 압축과 설치 페이지 생성을 담당하는 크로스 플랫폼 빌드
- `test/`: 좌석 인접성·우선순위·매진/통로 처리와 북마클릿 URL 인코딩 회귀 테스트

## 주의사항

- CGV 화면 구조가 다시 바뀌면 동작하지 않을 수 있습니다.
- 5초보다 짧은 간격으로 요청하지 않으며, 오류가 5회 연속 발생하면 자동 감시를 중단합니다.
- 실제 좌석 확보는 CGV의 잔여석 상태와 예매 정책에 따라 실패할 수 있습니다.
- 사용자는 CGV 이용약관과 관련 정책을 준수할 책임이 있습니다.
