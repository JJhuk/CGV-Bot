# CGV / 메가박스 자동 예매 북마클릿

CGV와 메가박스의 좌석 현황을 일정 간격으로 확인해, 사용자가 지정한 선호 좌석 중 가장 우선순위가 높은 연속 좌석을 선택하는 북마클릿입니다. 결제 자체는 자동으로 완료하지 않습니다.

각 사이트의 공개 DOM과 화면에 제공되는 새로고침 동작만 사용합니다. 사이트 내부의 비공개 예매 API를 직접 호출하지 않습니다.

## 설치

Node.js 18 이상이 필요합니다.

```sh
npm install
npm run build
```

빌드하면 사이트별 설치 페이지 두 개가 생성됩니다.

- `dist/index.html`: **CGV 자동 예매**
- `dist/megabox.html`: **메가박스 자동 예매**

원하는 설치 페이지를 브라우저에서 열고 자동 예매 링크를 북마크바로 드래그합니다. 두 사이트를 모두 사용하려면 북마크 두 개를 각각 추가하세요.

## CGV 사용 방법

1. CGV에서 영화, 극장, 상영 시간과 관람 인원을 선택합니다.
2. 좌석 영역의 **선택** 버튼을 눌러 큰 좌석 선택 창을 엽니다.
3. 북마크바의 **CGV 자동 예매**를 실행합니다.
4. 원하는 좌석을 선호 순서대로 클릭합니다. 현재 매진된 좌석도 선호 좌석으로 지정할 수 있습니다.
5. **감시 시작**을 누릅니다.
6. 조건에 맞는 연속 좌석이 생기면 CGV의 실제 좌석 선택 동작을 실행하고 알립니다.

기본값은 좌석 확보 후 결제 화면까지 자동으로 이동합니다. 원치 않으면 감시를 시작하기 전에 해당 옵션을 끄세요.

## 메가박스 사용 방법

1. 메가박스 **빠른예매**에서 영화, 극장, 날짜와 상영 시간을 선택합니다.
2. 좌석 화면에서 관람 인원을 선택합니다.
3. 북마크바의 **메가박스 자동 예매**를 실행합니다.
4. 원하는 좌석을 선호 순서대로 클릭합니다. 현재 예매 완료된 좌석도 선호 좌석으로 지정할 수 있습니다.
5. **감시 시작**을 누릅니다.
6. 조건에 맞는 연속 좌석이 생기면 메가박스의 실제 좌석 선택 동작을 실행하고 알립니다.

메가박스용 북마클릿은 좌석을 갱신할 때 사이트가 제공하는 **초기화** 동작을 사용하고, 선택해 둔 관람 인원을 자동으로 복원합니다. 기본값은 좌석 확보 후 다음 화면으로 이동하며, 실행 패널에서 끌 수 있습니다.

## 개발

```sh
npm test
npm run build
```

- `bookmarklet.js`: CGV DOM 어댑터, 선호 좌석 UI와 폴링 상태 머신
- `megabox-bookmarklet.js`: 메가박스 좌석 프레임 어댑터, 인원 복원과 폴링 상태 머신
- `build.js`: 두 북마클릿의 Terser 압축과 설치 페이지 생성을 담당하는 크로스 플랫폼 빌드
- `test/`: 좌석 인접성·우선순위·매진/통로 처리와 북마클릿 URL 인코딩 회귀 테스트

## 주의사항

- CGV 또는 메가박스의 화면 구조가 바뀌면 동작하지 않을 수 있습니다.
- 각 사이트의 화면 갱신 제한보다 짧은 간격으로 요청하지 않으며, 오류가 반복되면 자동 감시를 중단합니다.
- 실제 좌석 확보는 각 사이트의 잔여석 상태와 예매 정책에 따라 실패할 수 있습니다.
- 사용자는 각 예매 사이트의 이용약관과 관련 정책을 준수할 책임이 있습니다.
